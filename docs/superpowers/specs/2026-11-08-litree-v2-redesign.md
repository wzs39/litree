# LitTree v2 体验重构设计（spec 附录）

日期：2026-11-08 ｜ 触发：M1+M2 实测体验不合格（详见诊断记录），用户指示重做
决策（用户已确认）：**视图重构保 core ／ 路线首页 ／ 详情确认点亮**

## 0. 诊断结论（实测证据，浏览器逐层走查）

- **致命**：知识点只有名字胶囊，summary/资源/练习/证据全部无 UI（DetailPanel 缺失）；满屏锁定无引导（M1 视图 15 单元 14 锁）；首次点亮需 5 层钻取
- **交互**：click/dblclick 冲突（面板闪现常驻遮挡）；浏览器返回键退出应用（无 URL 路由）；stub 徽章噪声+截断+箭头歧义；标题硬截断 12 字
- **视觉**：进度环数字溢出卡片；画布利用率低；根视图像菜单；elk 边交叉多
- **正常**：点亮 80ms、动效联动、门控语义、零 console 错误
- **经验**：e2e 只断言功能存在不断言体验质量；DetailPanel 推迟 M3 是错误裁决（对学习工具它是本体）；交付即杀 dev server

## 1. 信息架构

- **hash 路由**：`#/home`（路线首页）、`#/tree/<containerId 链 a/b/c>`（钻取视图）、节点选中态 `?node=<id>`。浏览器返回键 = 视图栈回退；刷新恢复位置；URL 可分享
- **路线首页 `#/home`**：
  - 顶部：总进度环 + XP + 「继续学习」按钮（定位：progress 最近点亮记录 → 其所属 unit → 所属路线/lane）
  - 路线卡片 ×6（数据源 pack.routes，新增可选字段）：名称、说明、单元序列（点亮状态标记）、路线进度
  - 「全部学科」次级入口 → 现有根视图（视觉修正版）
- **钻取视图**：保留 根(学科) → lane → unit 三层；**章不再是独立视图层级**——unit 视图内章渲染为分组标题条（参与 elk 分层、非交互节点），其下叶子直接平铺（>20 的单元默认展开第一个未完成章，其余折叠为标题条）

## 2. DetailPanel（核心新增，右侧滑出 320px）

- 标题（完整）+ 领域色条 + kind 徽章（主干/选修/里程碑）
- summary、resources（可点击外链 + lang 标）、exercises、evidence（引用样式）
- 前置链：closure 列表（状态标记；跨视图项点击跳转）；后继：出边去重 top3 + 溢出计数
- 动作区：leaf → 「我已掌握，点亮」（available 才可用；locked 显示"还差 N 步·缺 <前置名>"）；unit → 进入 / 批量点亮；branch → 进入
- **点亮 = 详情面板确认**（替换无脑单击）；旧左下角 Inspector 停用
- stub 改制：画布每锚点最多 1 条聚合徽章（"N 条外部依赖 »"），点击开 DetailPanel 依赖区；画布不再逐边画跨视图徽章

## 3. 交互语义

- 单击节点 = 打开/更新 DetailPanel；双击容器 = 进入（面板保持，不再闪现独立 Inspector）
- 锁定单元卡片直接渲染「🔒 还差 N 步 · 缺 <最深未点亮前置名>」
- 画布：缩放平移保留现有实现；视图切换重置、进度变化保留（已有）

## 4. 视觉规范（在 §9 基础上修订）

- 卡片顶部 2px 领域色条；进度环内嵌卡内（数字置于卡底部，不溢出）
- 标题禁用 slice 截断：两行 tspan 换行 + 字号自适应
- elk：`nodeNode 28 / betweenLayers 56`、`edgeRouting: NETWORK_SIMPLEX`；小视图 scale 上限 1.0
- 路线首页为 DOM 卡片流（非 SVG）

## 5. 数据（converter 增量）

- `litree/pack-v1` 增加可选 `routes: [{ name, note, ids[] }]`；converter 读上游 `skilltree.routes`（6 条），校验 ids 存在；dev-mini 增加 2 条演示路线
- 不改 nodes/edges/进度结构（core 与既有测试不动）

## 6. 测试与验收

- e2e 全部改用 **cs-math 真实包**走关键路径：home → 路线 → 单元 → 详情 → 确认点亮 → 浏览器返回键回退 → 刷新恢复位置；dev-mini 仅保留冒烟
- 新增体验断言：标题元素不溢出卡片 bounding box；锁定卡含引导文案；routes 首页可达
- **交付规约**：交付时 dev server 保持运行并附验收清单（修复"交付即杀服务"）

## 7. 非目标

- 编辑器（M3）、minimap/搜索（M4）不变；不改 core 图逻辑与进度模型
